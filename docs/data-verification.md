# 데이터 연결 검증 (2026-09-20)

## 실행
- 개발: npm run dev (React 5173, API 3100)
- 빌드 실행: npm start (http://localhost:3100)
- index.html 파일을 직접 열면 React 모듈과 API가 동작하지 않습니다.

## 확인 결과
- 국토부 매매: 서울 25개 구, 2026년 7~9월 75/75 요청 성공. 취소 제외 10,106건, 최신 계약일 2026-09-18.
- 카카오: 도봉파크빌2 위치 및 도봉산역 응답 확인.
- 전월세: 2026-09-24 서비스 승인 및 URL 변경 후 수집 API 연결 확인. 최근 12개월 서울 25개 구를 완전 수집한 경우에만 DB 원장을 교체하며, 일부 실패 시 이전 원장을 유지함.
- 공동주택 기본정보: 요청 성공, 테스트 단지 검색 결과 0건. 단지 식별자 및 공급원 범위 추가 확인 필요.
- Supabase: DNS lookup에서 ENOTFOUND 재현. 인증 및 테이블 요청 이전 단계에서 실패. SUPABASE_URL의 프로젝트 주소와 대시보드의 실행/일시중지/삭제 상태 확인 필요. ENOTFOUND만으로 프로젝트 삭제라고 단정할 수 없음. 외부 DB 저장 성공으로 취급하지 않음.
- 로컬 원장: data/cache/transactions.json에 원자적으로 저장. 1시간 캐시. 만료 후 재수집 실패하면 마지막 원장과 경고 반환.
- Vercel에서는 /tmp 저장이 임시이므로 영구 저장소 복구 전 운영 배포 완료로 볼 수 없음.
- 현재 판매 매물, 호가, 토지거래허가 원장은 공급원 미연결. 실거래나 샘플 숫자를 이 데이터로 대체하지 않음.

## 데이터 의미
신고가 계산은 수집기간 내 동일 자치구·동·단지·정확한 전용면적의 이전 계약일 최고가와 비교합니다. 전체 역사상 신고가는 아닙니다. 같은 날 거래는 시간 순서를 알 수 없어 상호 비교하지 않습니다.
원본 취소/정정은 다음 수집 때 로컬 스냅샷을 교체해 반영합니다. 기존 Supabase upsert 테이블은 별도 정합성 점검과 취소 이력 동기화가 필요하며 현재 화면 원장으로 사용하지 않습니다.
서버 API와 배포 함수는 동일 핸들러를 사용합니다. /api/health는 설정 여부만 알려주며 인증 성공을 보장하지 않습니다.

## 화면 변경
홈·실거래·최고가 경신 화면에 날짜별 원장 컴포넌트 적용.
날짜 선택 → 자치구/가격대 그룹 → 단지별 집계 펼치기 → 개별 거래 상세로 연결.
매물·호가는 판매 중인 매물 공급원이 없고 토지허가는 행정 허가 원장 수집기가 미구현된 상태이며, 국토부 매매 API 연결 실패가 원인은 아님.
